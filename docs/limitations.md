# 지원 범위와 제한

기본 정적 분석기는 저장된 Python 소스의 구문과 제한된 이름 해석을 기록합니다. 기본 명령은 코드를 실행하지 않습니다. 별도 `runtime` 명령은 실제 실행의 제한된 동기 Python 관측을 추가하며 완전한 호출 그래프를 보장하지 않습니다.

## 연결할 수 있는 범위

같은 모듈의 유일한 직접 정의, 모듈 수준 함수의 재귀, 명시적인 import·별칭·상대 import, 명시된 모듈 멤버 호출을 이름 가림 검사 후 연결합니다. 클래스 생성 표현식은 클래스 노드에 연결합니다. 객체를 생성한 뒤 변수로 전달되는 타입은 전파하지 않습니다.

매개변수·대입·삭제·반복문·with·except·패턴·lambda·comprehension의 이름 가림을 보수적으로 취급합니다. 재대입이 범위 내 한 번이라도 있으면 호출 시점과 무관하게 미해결일 수 있습니다. 함수 정의의 기본값·데코레이터·클래스 기반식은 바깥 실행 범위에 속하며 타입 힌트 호출은 annotation으로 구분합니다.

## 미해결로 남기는 경우

0.4.0에서 모듈·지역·매개변수·클래스 본문 변수와 읽기/쓰기/삭제, 함수·클래스 참조, 명시적 상속, 변수 간 대입식 참조를 추가했다. 이는 어휘적 관계이며 실제 값·실행 성공을 뜻하지 않는다. 객체 속성(`self.x` 포함), 람다·컴프리헨션 내부 변수 참조, 구조 분해 대입의 변수 간 값 대응은 추정하지 않는다. 한 스코프의 이름에 정의/import/대입이 혼합되면 변수 관계도 보수적으로 생략한다. `global`·`nonlocal`의 변수 정체성 연결과 해당 변수 값의 호출 대상 해석은 별개다. 클래스의 현재 줄/뒤쪽 바인딩으로 앞쪽 읽기를 연결하지 않으며 이때 전역 fallback도 생략한다. 미지원 변수 참조를 모두 별도 unresolved 간선으로 저장하지는 않는다.

- `self.method()`, `obj.method()`, `super().method()` 등 객체 타입·상속을 알아야 하는 호출.
- 매개변수 함수, 함수 값의 대입 전파, closure·global·nonlocal을 통한 값 전달.
- 재수출, wildcard import, 데코레이터로 의미가 바뀔 수 있는 정의, 중복·조건부 정의.
- 동적 import, monkey patch, import hook, sys.path 변경, metaclass의 실행 효과.
- namespace package 및 다중 소스 루트의 완전한 해석.
- 설치 환경에 따른 라이브러리 심볼·실제 가용성, 일반 참조와 런타임 흐름.

정적 규칙은 일반 Python 프로그램 전체에 대한 완전성·건전성을 보장하지 않습니다. 지원 규칙으로 연결된 관계도 런타임에 같은 대상이 실행됨을 보장하지 않습니다. 분기 도달 가능성·반복 횟수·타입 힌트 평가 여부는 계산하지 않습니다.

`external`은 명시적 import가 분석 인덱스 밖의 이름이라는 분류입니다. 잘못된 소스 루트 또는 범위 밖 내부 코드일 수도 있습니다. 알려진 제외 파일·내부 패키지의 빠진 하위 모듈은 module_not_indexed로 남깁니다. import 루트는 최상위 패키지의 부모로 선택하세요.

내장 함수는 실행 중인 분석기 Python의 내장 이름을 기준으로 판별합니다. 이름 가림을 검사하지만 런타임에 내장 객체를 교체하는 효과는 모델링하지 않습니다.

## 입력과 출력

`.py`만 읽고 `.pyi`·노트북·다른 언어는 분석하지 않습니다. 소스 루트와 제외 패턴은 보고서에 기록합니다. 링크와 junction을 따라가지 않으며 제외 디렉터리 내부 파일 수를 추정하지 않습니다. `.gitignore`는 자동 해석하지 않습니다.

파일별 읽기·인코딩·파싱 오류를 격리합니다. 분석 중 변경은 해시 재확인으로 진단하지만, 재확인 직후 파일이 바뀌는 경우까지 막지는 못합니다. 분석된 내용은 그 실행이 읽은 자료를 뜻합니다.

HTML은 외부 서버나 외부 자원 없이 동작합니다. 그래프에는 HTML에 내장된 JavaScript가 필요하며 표·트리·상세 정보는 JavaScript 없이도 읽을 수 있습니다. 그래프의 근거 링크는 접힌 상세를 펼칩니다. 기존 읽기 안내의 앵커 이동이 자동으로 펼쳐지지 않는 브라우저에서는 해당 파일을 직접 펼치세요. 대규모 보고서는 브라우저 메모리와 표시 시간이 커질 수 있습니다. 그래프 표시 상한은 전체 보고서 파일 크기나 메모리 사용량의 상한이 아닙니다.

업무 목적·정확한 입력 및 반환 값·오류나 취약점·완전한 변경 영향을 판정하지 않습니다. 작성자의 docstring도 실제 구현과 다를 수 있습니다. VS Code·Git 기능은 포함하지 않습니다.

## 그래프와 선택 AI

그래프는 원래 정적 관계의 부분 표시입니다. 표시한 부분을 전체 호출 관계로 해석하지 마세요. 같은 출발·도착·유형의 관계를 묶되 원본 근거를 모두 보존합니다. 미해결·외부·내장 이름을 실재 함수 노드로 만들지 않습니다.

전체 구조는 분석 범위 내 파일·폴더의 요약이며 외부 시스템이나 제외된 파일을 포함한 아키텍처가 아닙니다. 폴더는 직접 포함 파일을 묶은 표시 그룹으로 Python 패키지 여부를 판정하지 않습니다. 호출 흐름은 정적으로 연결된 호출 또는 관측 호출의 도달 관계이며 분기·반복·실행 순서를 확정하지 않습니다. 표시 상한을 넘는 경우 검색·폴더 요약으로 범위를 좁히세요.

`assist`의 검색은 단어 일치 방식이며 자연어 의미 검색이 아닙니다. 문맥에 포함하지 않은 코드나 동적 호출은 설명의 근거가 될 수 없습니다. 큰 정의는 문자 수 예산 때문에 빠질 수 있습니다. 대상이 빠지면 AI 요청을 중단합니다.

AI 요청은 `study --ai`, `assist explain`, `review --ai`, 또는 `runtime --ai`를 명시적으로 실행할 때 설정한 서버로 전송합니다. 근거 ID·해시·위치의 유효성을 검사하지만 설명의 의미 정확성을 보장하지 않습니다. 관계 제안은 정적 결과에 반영하지 않습니다. 모델별 출력 품질·모든 호환 서버·프롬프트 주입에 대한 완전한 방어는 검증하지 않았습니다. 상세 범위는 [F·I 확장 계약](extensions.md)과 [동적·AI 후처리 계약](runtime.md)을 따릅니다.

## 동적 실행

진입점 후보의 점수는 최상위 호출·호출자·import 관계에 근거한 추천이며 업무 시작점이나 실행 성공을 보장하지 않습니다. 프레임워크 진입점·외부 호출·콜백을 정적 분석에서 놓칠 수 있습니다. 함수 후보 실행에는 실제 인자가 필요하며 생성자·메서드·비동기·제너레이터·중첩 함수의 실행 시나리오를 자동 만들지 않습니다. 함수가 속한 모듈을 로딩할 때 최상위 부작용은 발생합니다. 먼저 `--discover`로 실행 없이 후보와 근거를 확인할 수 있습니다.

`review` 후처리와 `runtime --ai`는 제공된 일부 구조와 관측 집계만으로 설명합니다. 근거 ID가 유효해도 모델의 해석이 맞다는 뜻은 아닙니다. 원문 전체·프로그램 인자·로그는 보내지 않지만 상대 경로·정의 이름·docstring 일부는 전송됩니다. AI 실패나 미사용 상태에서도 기본 구조·실행 보고서는 제공됩니다.

`review`는 같은 프로젝트·스냅샷의 저장된 정적·동적 결과만 결합하며 여러 소스 버전이나 여러 실행을 자동 병합하지 않습니다. HTML 단독 파일이 아니라 함께 저장된 JSON·manifest가 필요합니다. 원본 프로그램을 다시 실행하지 않으므로 새로운 실행 경로를 관측하는 기능은 아닙니다. AI 결과는 별도 폴더에 생성하고 기존 보고서는 보존합니다.

호출 타임라인과 함수별 시간은 추적 중 측정한 벽시계 시간입니다. 추적기·외부 코드·대기 비용을 포함하며 정밀 프로파일링 결과가 아닙니다. 관측 자식 제외 시간도 완전한 자체 실행 시간은 아닙니다. 미완료 호출은 종료 시간을 추정하지 않습니다. 함수 실행 관측 비율은 정적으로 수집한 모든 함수·메서드 기준으로 지원 범위 밖 함수도 포함하며 행·분기 커버리지와 다릅니다.

`runtime`과 `study`는 대상 코드를 실제 실행합니다. 기본 추적은 단일 최초 스레드의 일반 동기 Python 코드만 추적하며 비동기·제너레이터·다른 스레드·자식 프로세스·C 내부 실행은 범위 밖입니다. 호출 출발점은 상위 Python 프레임이며 C 콜백·암시적 실행을 거친 관계일 수 있습니다. 한 입력에서 관측되지 않은 코드는 미사용을 뜻하지 않습니다.

추적은 실행 시간을 늘리고 프로그램 동작에 영향을 줄 수 있습니다. 별도 프로세스는 샌드박스가 아니며 시간 제한도 임의 자식 프로세스나 외부 시스템의 부작용까지 되돌리지 않습니다. 대상 패키지·실행 환경은 별도 준비해야 합니다. 입력 값·반환값을 수집하지 않지만 명령행 인자와 대상 출력에는 값이 포함될 수 있습니다. 상세 계약은 [동적 분석 문서](runtime.md)를 따릅니다.

## AI 자동 입력과 선택 도구

`study`는 합성 CLI·함수 인자, 미리 생성한 표준입력, 작은 JSON/CSV/TXT를 사용합니다. 실시간 대화나 인증정보·외부 서비스·복잡한 객체 준비를 대신하지 않습니다. AI가 만든 입력과 근거는 저장하고 다음 요청에 전달합니다. README와 입력 구문의 문자열도 전송되므로 전체 소스나 로그를 보내지 않는다는 것만으로 민감정보 비전송을 보장하지 않습니다.

디렉터리 역할 설명은 분석한 Python 파일이 있는 디렉터리와 제한된 문맥에 한정됩니다. 모든 비소스 디렉터리의 업무 의미를 판정하지 않습니다. 문맥은 후보 40개, 입력 구문을 읽을 파일 60개, 디렉터리 근거 60개 등으로 제한하며 AI 설명도 최대 디렉터리 30개·파일 30개입니다. 대규모 프로젝트에서는 분석 범위를 좁혀 사용하세요.

매 시도 새 복사본을 만들며 숨김 항목·링크·환경 디렉터리·일부 키 파일을 제외합니다. 따라서 원래 개발 환경을 완전히 재현하지 않습니다. 복사본은 보안 격리가 아니며 다른 환경 변수나 절대 경로·네트워크 접근을 차단하지 않습니다. 실제 모델의 입력 생성 성공률·프로젝트 설명 정확도는 측정하지 않았습니다.

DynaPyt 함수 진입·분기와 Scalene CPU·메모리 측정은 별도 실행 관측입니다. 도구 실패·미설치·관측 없음은 해당 상태로 남기며 기본 결과를 대체하지 않습니다. 메모리 프로파일 실패 후 CPU 대체 실행도 실패할 수 있습니다. 프로파일 원자료는 로컬에 저장하고 AI에는 제한된 위치별 수치만 제공합니다. 각 시도의 시간축은 합치지 않습니다.
